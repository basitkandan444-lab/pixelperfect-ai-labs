## ⏭️ Exact Next Commands

### 1. Provision Cloudflare Secrets

Run the following commands on the deployment workstation:

```bash
# Set the Paddle Sandbox API Key
wrangler secret put PADDLE_SANDBOX_API_KEY

# Set the Paddle Sandbox Webhook Secret
wrangler secret put PADDLE_SANDBOX_WEBHOOK_SECRET

# Set the Public App Origin
wrangler secret put PUBLIC_APP_ORIGIN
# (Value to enter: https://imageenhancer.online)
```

### 2. Configure Paddle Sandbox Webhook

1. Log into your **Paddle Sandbox Dashboard**.
2. Navigate to **Developer Tools > Webhooks > Add Endpoint**.
3. Set the endpoint destination URL:
   `https://imageenhancer.online/api/public/paddle/webhook`
4. Check the following required events:
   - `transaction.completed`
   - `transaction.paid`
   - `subscription.created`
   - `subscription.updated`
   - `subscription.canceled`

# Implement **SECTION 1 ONLY: PIXEL PERFECT PRO™ DESIGN DNA**. Do not redesign pages, navigation, hero sections, pricing, dashboard, enhancement logic, backend, routing, APIs, or functionality in this task. First audit the existing frontend and preserve all current behavior. Then establish one cohesive premium design system inspired by the precision of Linear, trust/clarity of Stripe, visual restraint of Apple, and calm intelligence of Anthropic/Claude, but create a distinct Pixel Perfect Pro identity rather than copying any brand. Define and implement the global visual foundations: typography hierarchy, font weights, line heights, letter spacing, spacing scale, responsive sizing, color tokens, semantic colors, surface hierarchy, borders, radii, shadows, gradients, glass/depth treatment, focus states, disabled states, and a disciplined motion language. Create reusable design tokens/variables so future sections inherit the same system instead of introducing random values. Establish consistent component states for buttons, inputs, cards, dialogs, badges and interactive elements: default, hover, active, focus, disabled, loading, success and error. Use subtle premium motion and spring-like transitions where they improve feedback, but keep everything fast, GPU-friendly and accessible; respect reduced-motion preferences. Improve visual hierarchy, contrast, density and consistency across the EXISTING UI without changing its information architecture. Remove obvious visual inconsistency, arbitrary spacing, random border radii, mismatched shadows, inconsistent typography and conflicting colors. Do not add heavy libraries or unnecessary dependencies. The result should feel calm, premium, precise, modern and highly intentional, with a strong image-focused visual identity suitable for a world-class image product. Before finishing, audit the entire frontend for design-token consistency and verify desktop, tablet and mobile behavior. **Acceptance criteria:** one coherent design language, reusable tokens, consistent component states, responsive foundations, accessible focus/reduced-motion behavior, no functional regressions, no unnecessary dependencies, and no section-specific redesign outside this Design DNA scope. End with a concise before/after audit listing what changed and any remaining design debt. Do not proceed to Section 2.
